# Docs

Group-level project documentation, architecture diagrams, and release
deliverables. Per-student documentation lives under `student-N/docs/`.

| Folder | Contents |
|---|---|
| [`release-0/`](release-0/) | Release 0 deliverables: the [deliverable index and evidence map](release-0/README.md), [integrated architecture](release-0/integrated-architecture.md), [Docker Compose architecture](release-0/compose-architecture.md), and [DevOps pipeline](release-0/devops-pipeline.md) |
| [`agentic-loop-records/`](agentic-loop-records/) | Finalised JSON execution records from the shared two-model agentic loop, and the [rules for what a report-ready record must contain](agentic-loop-records/README.md) |
| [`Project_Specifications/`](Project_Specifications/) | The [project specification](Project_Specifications/Project_Specifications.md) and the [Release 0 brief](Project_Specifications/Release_0_brief.md) |

Later releases should add their own folder here (`release-1/`, `release-2/`)
rather than extending `release-0/`.
