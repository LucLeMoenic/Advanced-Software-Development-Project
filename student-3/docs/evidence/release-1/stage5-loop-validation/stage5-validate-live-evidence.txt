direct Ollama call beforehand. This is a real, reproducible timeout under
current host load, not a code defect: the same question succeeded with a
full grounded answer and citations in Stage 3's live browser test (see
student-3/docs/evidence/release-1/stage3-frontend-panels/02-rag-answer-success-with-citations.png),
proving the underlying contract works when the host has enough headroom.

(mcp is pure retrieval; an unanswerable question short-circuits to the
fixed insufficient response before ever calling Ollama) and passed cleanly
every time.
