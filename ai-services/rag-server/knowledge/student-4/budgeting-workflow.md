# Practical budgeting workflow in the tracker
Source: `student-4/backend/Api/BudgetEndpoints.cs`, `student-4/backend/Services/DashboardCalculator.cs`, `student-4/docs/requirements.md` | Reviewed: 2026-10-01 | Operating guidance derived from application behavior; no external financial claims.

For a trip, create a journey label, set a limit and date period for each spending category, then record each expense against the matching budget using its purchase date and original currency. Review the dashboard's planned, actual, remaining, and percentage-used values by category as expenses are recorded.

This knowledge base provides general tracker guidance and has no access to saved expenses or current journey totals. Use the dashboard or the read-only budget check for current spending figures; do not infer a remaining balance from these notes or from an exchange-rate example.
