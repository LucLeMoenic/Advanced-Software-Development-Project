Travel Planner

Five independently owned microservice stacks, one trip. Each feature below runs its own frontend, backend, and database container.

Features

  • Accommodation Recommender — Student 1 localhost:5101
  • Itinerary Planner — Student 2 localhost:5102
  • Local Experiences & Attractions — Student 3 localhost:5103
  • Budget & Expenses — Student 4 localhost:5104
  • Travel Logistics & Advisory — Student 5 (Alex Chen) localhost:5105

Links use http://localhost:PORT so each feature can be opened and marked directly against the running Compose application. Start everything with docker compose up --build from the repository root.
