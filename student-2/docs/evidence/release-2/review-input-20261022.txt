Multi-Agent Workflow Review
--------------------------
Current intended Student 2 workflow:
  frontend -> backend -> exact MCP edit preview -> shared native
  Planner -> Worker -> Reviewer -> explicit human assessment decision ->
  separate preview confirmation -> database save.
An approved assessment is not itself a save. Corrections and partial acceptance
concern assessment text, not partial execution of an indivisible signed preview.
The preview token hash binds acceptance to the proposed edit; stale snapshots,
expiry and database revision checks remain authoritative.

It records genuine agent outputs, Reviewer pass, unchanged saved trip and audit

revision. It explicitly has no human decision. Audit entries are filtered to
that workflow and are not a standalone complete audit chain.

a documented historical claim, not independently checked execution evidence.
